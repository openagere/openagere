# Security Policy

Thank you for helping us keep Agere secure!

## Reporting Security Issues

Keeping Agere reasonably secure relies on responsibly disclosed reports from the community.

If you believe you have discovered a vulnerability, please e-mail **security@openagere.com**
with sufficient detail so we can assess and reproduce it. We ask that researchers act in good
faith and refrain from harming users' data or service availability.

Please also see [Responsible disclosure](docs/contributing.md#security--responsible-ai)

## Vulnerability Disclosure Program

Reports are acknowledged on best effort according to severity and reproducibility.

## How to operate AGERE safely

For details on Agere security boundaries, including managed execution permissions, approvals, and network controls, see [Agent approvals & security](https://developers.openagere.com/agere/agent-approvals-security).
